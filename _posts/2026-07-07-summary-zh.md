## [腾讯发布 Hy3：295B MoE 模型，21B 活跃参数，Apache 2.0 许可](https://simonwillison.net/2026/Jul/6/hy3/#atom-everything) ⭐️ 8.0/10

腾讯发布了 Hy3，一个 295B 参数的混合专家（MoE）模型，拥有 21B 活跃参数和 3.8B 多令牌预测（MTP）层参数，采用 Apache 2.0 许可证。该模型性能优于同尺寸模型，并在 OpenRouter 上免费提供至 2026 年 7 月 21 日。 Hy3 提供了一个具有竞争力的高效开源替代方案，可能降低用户对大型专有模型的依赖成本。其出色性能和 Apache 2.0 许可证可能影响 AI 社区的模型选择和部署策略。 完整模型在 Hugging Face 上大小为 598GB，上下文长度为 256K，而 FP8 量化版本为 300GB。该模型采用了 MTP 层，这是一种同时预测多个未来令牌的技术，可提高训练效率。

rss · Simon Willison · Jul 6, 23:57

**背景**: 混合专家（MoE）是一种机器学习技术，每次输入仅激活部分专家网络，从而以更少的活跃参数实现高效扩展。FP8 量化通过以 8 位浮点格式而非 16 或 32 位存储权重来减少模型内存占用。多令牌预测（MTP）训练模型同时预测多个未来令牌，提高数据效率。这些技术共同使 Hy3 在可控资源需求下实现强劲性能。

## [Cloudflare 推出 Workers 缓存](https://blog.cloudflare.com/workers-cache/) ⭐️ 7.0/10

Cloudflare 发布了 Workers 缓存功能，这是一种区域分层缓存，直接位于 Worker 入口点之前，并通过标准 HTTP 标头进行配置。 Workers 缓存通过直接提供缓存响应而不执行 Worker，降低了延迟和使用成本，使无服务器应用更高效且更具成本效益。 该缓存采用区域分层策略，在访问上一级缓存之前会先检查靠近低层级的区域数据中心，并且可通过标准 HTTP 缓存标头实现无限组合。

rss · Cloudflare Blog · Jul 6, 13:00

**背景**: Cloudflare Workers 是一个在边缘运行代码的无服务器计算平台。以前，使用 Workers 进行缓存需要借助缓存 API 或让 Worker 位于缓存之后。现在 Workers 缓存置于 Worker 之前，使得缓存响应可以完全跳过 Worker 执行，从而提升性能并降低成本。
