## [Claude Opus 5 系统提示词要求确认出口管制暂停事件](https://simonwillison.net/2026/Aug/9/claude-opus-5-system-prompt/#atom-everything) ⭐️ 8.0/10

西蒙·威利森（Simon Willison）摘录了 Anthropic 公开发布的 Claude Opus 5 系统提示词。该提示词指示 Claude 准确确认 Claude Fable 5 和 Claude Mythos 5 因美国商务部出口管制于 2026 年 6 月被暂时停用，并将出口管制问题视为当前政治话题。 这之所以重要，是因为它具体展示了 Anthropic 如何通过系统提示词让模型在训练数据截止日期之后仍然与真实世界事件保持一致，尤其是涉及监管的政治敏感事件。这体现了一种透明度机制，其他 AI 实验室可能会效仿，也展示了企业在国际贸易管制下如何兼顾合规与事实一致性。 该 Opus 5 系统提示词包含一段明确说明，列出了具体日期：Fable 5 和 Mythos 5 于 2026 年 6 月 9 日发布，6 月 12 日被停用，6 月 30 日管制解除，7 月 1 日恢复访问。提示词还指示 Claude 在被问及时如实确认停用事件，将出口管制作为政治话题给出公正准确的描述，提供 Anthropic 官方声明链接，并在可搜索时主动核查是否有更新信息。

rss · Simon Willison · Aug 9, 23:31

**背景**: 系统提示词是定义大语言模型行为方式的隐藏指令，包括如何处理超出其训练数据截止日期的最新事件。Claude 是 Anthropic 开发的一系列大语言模型；Claude Opus 5 是其 2026 年 7 月 24 日发布的能力最强的主流模型，而 Claude Fable 5 和 Claude Mythos 5 是 2026 年推出的另一条产品线，带有不同的安全防护设置。2026 年 6 月，美国商务部的出口管制导致 Anthropic 暂时停用了 Fable 5 和 Mythos 5，这是真实发生的监管行动，Claude 只能通过系统提示词获知该事件。

## [GitHub Models 已退役，Actions 工作流受 brownout 影响](https://simonwillison.net/2026/Aug/9/github-models-is-now-retired/#atom-everything) ⭐️ 7.0/10

GitHub Models 已于 2026 年 7 月 30 日正式退役（见 GitHub changelog）。Simon Willison 报告说，他在 simonw/research 仓库中的 GitHub Actions 工作流因“退役 brownout”错误消息而失败，他已经改用带月度消费限额的 OpenAI API 密钥，并使用 GPT-5.6 Luna 生成摘要。 这次退役直接影响到那些依赖 GitHub Models 内置 API 密钥在 GitHub Actions 中运行 LLM 提示的开发者。这件事也反映出一种更广泛的趋势：AI token 的成本使平台方难以继续提供免费或补贴的 LLM 访问。 “退役 brownout”消息当时已经过时，因为工作流运行时退役已经完成。Simon 的工作流使用一次 LLM 调用来为仓库 README 生成文件夹摘要，他换成了带有月度消费限额的 OpenAI API 密钥。

rss · Simon Willison · Aug 9, 22:48

**背景**: GitHub Models 是 GitHub 提供的一个用于原型制作和试验 AI 模型的平台，提供网页 playground 以及跨 OpenAI、DeepSeek、Meta、Microsoft、xAI 等提供商的统一 API。它的关键优势在于，GitHub Actions 中的代码可以直接使用环境中已有的 GitHub API 密钥来执行提示，从而支持 GitHub Next 的“Continuous AI”模式——即在仓库中运行后台智能体，就像 CI 任务一样。Brownout（停电/降压）原指故意降低电压或短时停电以避免电网全面瘫痪，这里借指在最终下线前故意让服务暂时不可用，以提醒用户。GitHub 没有说明关停原因，Simon 猜测是编码智能体的使用模式使得免费或补贴 token 的成本过于高昂。
