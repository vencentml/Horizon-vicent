## [Claude Code 秘密嵌入隐写标记](https://thereallo.dev/blog/claude-code-prompt-steganography) ⭐️ 9.0/10

独立研究人员发现，Anthropic 的 Claude Code 工具在其请求中嵌入了隐写标记，通过隐藏的 API 基础 URL 和时区等线索来识别未经授权的使用行为。 这种秘密做法引发了对 AI 开发工具透明度和信任的严重担忧，因为用户并未被告知其交互被未经同意地标记。这可能影响开发者采用此类工具的意愿，尤其是在敏感项目中。 这些标记通过根据 API 基础 URL 和时区更改当前日期字符串嵌入到系统提示中。研究人员通过检查 Claude Code 二进制文件发现了这一功能。

## [最高法院支持宽泛的出生公民权](https://apnews.com/live/birthright-citizenship-decision-supreme-court-updates-06-30-2026) ⭐️ 9.0/10

美国最高法院维持了对出生公民权的广泛解释，确认了百年历史的先例，驳回了保守派大法官的挑战。 这一裁决重申几乎所有在美国领土上出生的儿童都是公民，影响移民政策和宪法；同时也凸显了最高法院内部深刻的意识形态分歧。 这项 6 比 3 的裁决按意识形态划线，据报道戈萨奇大法官的异议区分了非法移民子女和合法非移民子女。

## [ZLUDA 6 添加 32 位 PhysX 支持，回归业余项目](https://vosen.github.io/ZLUDA/blog/zluda-update-q1q2-2026/) ⭐️ 7.0/10

ZLUDA 6 已发布，新增了对 32 位 PhysX 的支持以及其他功能，同时该项目回归为非商业化的周末业余项目。 此版本使得未经修改的 CUDA 应用程序（包括使用 PhysX 的应用程序）能够在非 NVIDIA GPU 上运行，这有益于希望拥有硬件选择权的游戏和 GPU 计算用户。 32 位 PhysX 支持尤其值得关注，因为 NVIDIA 曾短暂考虑从 5000 系列 GPU 中移除它，后来因反对而撤回。

## [Cursor iOS 应用静默更改隐私设置](https://news.ycombinator.com/item?id=48737226) ⭐️ 7.0/10

用户报告称，安装并登录 Cursor iOS 应用后，其账户自动从严格的“隐私模式（旧版）”切换为限制较少的全新隐私模式，且未获得明确同意，也无法轻松恢复。 这一事件削弱了用户对 Cursor 数据隐私承诺的信任，尤其对于那些依赖旧版模式确保代码不被存储的开发者而言。同时也凸显了移动应用如何静默更改敏感网络服务设置的更广泛担忧。 这一更改是由移动应用设置过程中启用 Cloud Agents 的提示触发的，该提示切换了隐私模式而未说明后果。Cursor 员工 leerob 在 Hacker News 上确认，移动应用目前需要新的隐私模式，并且正在推送更新以澄清这一行为。

hackernews · zkldi · Jun 30, 18:33

**背景**: Cursor 是一款 AI 驱动的代码编辑器，提供“隐私模式”来控制代码存储。最初的“隐私模式（旧版）”严格禁止存储任何代码，而新的默认隐私模式允许为后台代理等功能存储代码。旧版模式已被弃用并隐藏在“额外选项”菜单下，但桌面用户仍可使用。iOS 应用的设置过程无意中将用户切换到了新模式，且未提供充分警告或返回方式。
