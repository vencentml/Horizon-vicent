## [Mozilla 正式弃用 asm.js，标志一个时代的结束](https://spidermonkey.dev/blog/2026/05/20/saying-goodbye-to-asmjs.html) ⭐️ 8.0/10

Mozilla 于 2026 年 5 月 20 日在博客中宣布弃用 asm.js，标志着随着 WebAssembly 成为高性能 Web 代码的标准，asm.js 的支持将结束。 这标志着 Web 技术的范式转变：asm.js 开创了浏览器中的接近原生性能，但已被 WebAssembly 取代，后者提供更好的性能、更小的包体积和更快的加载时间。开发者应迁移到 Wasm 以面向未来的高性能 Web 应用。 asm.js 是 JavaScript 的一个严格子集，通过 Emscripten 使 C/C++ 代码能在浏览器中运行，但其基于 JavaScript 的特性导致包体积更大、并且需要解析 AST，而 WebAssembly 的二进制格式则没有这些问题。Mozilla Firefox 从 22 版本开始率先对 asm.js 进行优化。

hackernews · eqrion · May 20, 12:01

**背景**: asm.js 是 Mozilla 对 Google 的 Native Client (NaCl) 和 Portable Native Client (PNaCl) 的回应，提供了一种无需浏览器插件即可在 Web 上以原生速度运行代码的方式。它证明了像 Figma 和 Unreal Engine 这样的复杂应用可以在浏览器中运行。WebAssembly 作为 asm.js 的后继者，是一种低级二进制指令格式，由 W3C 标准化并得到所有主流浏览器的支持。

## [llama.cpp b9254 为 Hopper+ GPU 添加 PDL 性能提升](https://github.com/ggml-org/llama.cpp/releases/tag/b9254) ⭐️ 7.0/10

llama.cpp 发布版本 b9254，引入对新型 NVIDIA Hopper+ GPU 的程序化依赖启动 (PDL) 支持，通过重叠内核执行来提升推理性能。该功能在兼容硬件上默认启用，并可通过 GGML_CUDA_PDL 环境变量切换。 此更新为在 Hopper+ GPU 上运行大型语言模型的用户带来了可衡量的性能提升，利用 GPU 硬件能力降低推理延迟。它展示了 llama.cpp 对前沿硬件的持续优化，惠及 AI 推理生态系统。 PDL 允许从属内核在其依赖的主内核完成之前启动，从而更好地利用 GPU。该实现包括基于启发式的 PDL 屏障、对许多内核（如 mul_mat_vec_q、rms_norm_f32、flash attention 内核）的注册，以及一个命令行开关。它被限制在 Ada 及以下 GPU，因此仅 Hopper+（如 H100）受益。

github · github-actions[bot] · May 20, 21:38

**背景**: llama.cpp 是一个流行的开源 C++ 实现，用于本地运行大型语言模型 (LLM)，针对包括 CPU 和 GPU 在内的各种硬件进行了优化。程序化依赖启动 (PDL) 是 NVIDIA 随 Hopper 架构引入的 CUDA 功能，允许对依赖的内核启动进行编程以实现重叠，从而减少启动开销并提高性能。Hopper 架构（如 H100 GPU）为 AI 工作负载带来了增强的张量核心和 Transformer 引擎能力。
