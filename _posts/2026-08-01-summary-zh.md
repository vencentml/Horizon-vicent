## [无状态 MCP 更新重燃热情，催生 mcp-explorer 等新工具](https://simonwillison.net/2026/Jul/31/stateless-mcp/#atom-everything) ⭐️ 8.0/10

2026 年 7 月 28 日，Model Context Protocol（MCP）2.0 规范（又称“无状态 MCP”）发布，将协议改为使用无状态 HTTP 请求。知名开发者 Simon Willison 表示，这一简化规范重新点燃了他的兴趣，并促使他本周构建了 mcp-explorer 和 datasette-mcp 等三个新工具。 这是 MCP 自发布以来最重要的变化，降低了客户端和服务端的实现难度，更适合构建可扩展的 Web 应用。这可能会加速 MCP 在 AI 智能体工具领域的采用，尤其是对于无法驾驭 shell 环境的较小型模型。 无状态规范消除了两步会话初始化的需要，一个带有“MCP-Protocol-Version”和“Mcp-Method”等头部的 HTTP 请求即可完成调用。这免去了服务端会话状态管理和路由问题，大幅降低了实现复杂度。

rss · Simon Willison · Jul 31, 23:13

**背景**: Model Context Protocol（MCP）是 Anthropic 于 2024 年 11 月推出的开放标准，用于向由大语言模型驱动的智能体暴露工具。无状态协议是指每个请求都携带全部所需上下文、服务器无需在请求之间保留会话状态的协议，HTTP 本身就是一个典型例子。旧版有状态 MCP 需要先发送初始化请求获取会话 ID，然后再发送第二个请求调用工具。转向无状态后，每次工具调用都自包含，提升了可见性、可靠性和可扩展性。
